    Enumeration TintModes

    Phaser Tint Modes.

    Tint modes are used by the Tint component to determine how the tint color is applied to the texture. The default mode is MULTIPLY. They are only used in WebGL.

    FILL: number

    Fill tint mode. The tint color replaces the texture color, but respects the texture alpha.

    You can use this mode to make a Game Object flash 'white' if hit by something.
