    release

    • release(): void

      End using the DrawingContext. This marks the context as not in use, so its framebuffer and texture are not needed any more and may be cleared at any time. This will finish any outstanding batches.

      If there are no locks on the DrawingContext, and it comes from a pool, it will be returned to its pool.

      Returns void

    setStencil

    • setStencil(
          enabled?: boolean,
          func?: number,
          funcRef?: number,
          funcMask?: number,
          opFail?: number,
          opZfail?: number,
          opZpass?: number,
          clear?: number,
          writeMask?: number,
      ): void

      Set the stencil parameters for the DrawingContext.

      Parameters

      • Optionalenabled: boolean

        Whether the stencil test is enabled. Default true.

      • Optionalfunc: number

        The stencil comparison function used to compare the reference value against the current stencil buffer value. Default GL_EQUAL.

      • OptionalfuncRef: number

        The reference value against which the stencil buffer value is compared during the stencil test. Default 0.

      • OptionalfuncMask: number

        The bitwise mask applied to both the reference value and the stencil buffer value before they are compared. Default 0xFF.

      • OptionalopFail: number

        The operation to perform if the stencil test fails. Default GL_KEEP.

      • OptionalopZfail: number

        The operation to perform if the stencil test passes but the depth test fails. Default GL_KEEP.

      • OptionalopZpass: number

        The operation to perform if the stencil test passes and the depth test passes or is disabled. Default GL_KEEP.

      • Optionalclear: number

        The value to clear the stencil buffer to. Default 0.

      • OptionalwriteMask: number

        The mask applied to the stencil buffer value when it is written. Set to 0 to prevent writing. Set to 0xFF to allow full writing. Default 0x00.

      Returns void
